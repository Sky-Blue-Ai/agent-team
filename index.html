使用帮助

常见问题与快捷操作，点击查看解答。

怎么录入内容？
页面上任意文字都可以直接点击修改，改动会实时保存；带虚线或「待填写」标记的位置是留给你填写的空白区域。
怎么新建和管理产品？
点击右上角「新建产品/灵感」创建卡片；在「流水线看板」里通过卡片上的阶段下拉框切换阶段，点击卡片进入产品详情页查看 9 阶段进度、字段与流转记录。侧边栏「产品矩阵」点击产品也会进入详情页。
九阶段分别是什么？
灵感 → 产品规划 → 战略决策 → 产品设计 → 产品开发 → 产品落地 → 产品上线 → 推广运营 → 动态调整。每张产品卡片都在这些阶段之间流转，详情页的进度环按当前阶段自动计算。
数据会丢吗？存在哪里？
数据写入项目目录下的 data.json，由本地服务负责保存；浏览器里也保留一份缓存作降级。关闭浏览器、重启服务后数据仍在。如果本地服务未启动而用文件方式打开，则退化为浏览器本地存储（仅当前浏览器可见）。
怎么换浏览器也能看到数据？
保持本地服务运行（双击「启动工作台.command」），其它浏览器访问同一个 http://127.0.0.1:8210/index.html 地址即可读取同一份 data.json。
备份与重置怎么做？
在「数据与备份」标签里点「导出备份」可下载完整 JSON；「导入备份」会用备份覆盖当前数据；「重置全部数据」会清空所有内容，操作前请先导出。
审计日志在哪里看？
主流水线底部的「全工厂审计日志与 SOP 流转动态」只展示最近 3 条摘要，点「查看全部」进入二级页面，可按类型筛选、搜索并导出日志。新建产品、阶段推进、设置修改与 AI 生成都会记录进去。
知识库和 SOP 怎么让 AI 自动生成？
在侧边栏「Agent 能力中心」进入「知识库」或「SOP 流程」，点「AI 自动生成」，选择知识条目 / SOP、范围（全工作台或单个产品）后先生成预览，勾选确认后写入。默认使用本地归纳引擎，离线可用；如需接入大模型，在本机启动服务前设置环境变量 PF_AI_API_KEY（可选 PF_AI_BASE_URL、PF_AI_MODEL），服务端会优先调用模型，失败时自动回退本地生成。密钥只留在本地服务，不会写入 data.json。
三个 Hub 是做什么的？
侧边栏「Agent 能力中心」下有 5 个独立入口：知识库、SOP 流程、Skill Hub、Agent Hub、Rule Hub，点击即可来回切换。Skill Hub 沉淀可复用技能与调用方式，Agent Hub 登记智能体的职责、模型、触发方式与边界，Rule Hub 记录硬约束、口径与安全边界。它们都能新建、编辑、删除，数据同样存在 data.json。
Agent 怎么真正执行任务（不配大模型也能用）？
在 Agent Hub 里点任意 Agent 卡片上的「运行」按钮，会打开执行弹窗，默认使用 WorkBuddy 原生执行：填好任务后点「生成执行简报」，系统会结合该 Agent 的角色/边界、生效中的规则、已登记的技能与工作台数据生成一份结构化简报，点「复制简报」粘贴到 WorkBuddy 对话即可让它真正推理执行，也可下载成 .md。这条路径不需要任何 API Key。想让工作台自己直接调用模型时，到「设置 → AI 引擎」填入 API Key（内置 DeepSeek 预设，也支持 OpenAI 及任意兼容接口），密钥保存在项目内 ai_config.json、不写入 data.json、不随备份导出；保存后回到运行弹窗切到「服务端模型推理」即可，结果可一键写入知识库。此前用环境变量 PF_AI_* 配置的方式仍然兼容且优先级最高。
